# Bioline (Meridian Bioscience)
**Official site:** www.bioline.com
**Protein markers found:** 0

Bioline Reagents Ltd (London, UK) was acquired by **Meridian Bioscience**. Its current product portfolio has been narrowed to DNA-only molecular weight markers and PCR/sequencing reagents; **it no longer sells any protein marker / protein ladder.**

## What was checked
- Homepage and Ladders/Markers category (https://www.bioline.com/hyperladder): only DNA ladders are listed — **HyperLadder™** (25 bp, 50 bp, 100 bp, 1 kb), **EasyLadder I**, and **HyperPAGE** (RNA size markers).
- Ladder selection guide (https://www.bioline.com/ladder-selection-guide.html): DNA ladders only, no protein markers.
- Catalog search "protein marker" (https://www.bioline.com/catalogsearch/result/?q=protein+marker): returns no protein marker product; only Proteinase K enzyme and DNA ladders.
- Catalog search "easysee": no results (the legacy **EasySee Protein Marker** is discontinued).
- Catalog search "BIO-25083" (legacy Bioline protein marker cat. #): returns only MangoTaq / MangoMix / MyTaq Red Mix — no protein marker.

## Note on historical products
The old Bioline catalog included a "Protein Marker / 500 µl" (e.g. cat. #BIO-25083, and an "EasySee" Western/chromogenic protein marker). These are referenced only as a stale "popular search" suggestion in the site's autocomplete but **no longer have live product pages** (404) and do not appear in the current catalog. Per the task definition they are considered discontinued → count = 0 for current offerings.
